# multi_culture

2학년 학생을 위한 다문화 거리 참여형 탐방 학습지입니다.

학생은 A~E반, 이름, 학번을 입력한 뒤 5개 지역 중 한 곳을 선택합니다.
선택한 지역은 NAVER 지도 앱으로 열고, 거리뷰에서 다문화 경관이 잘 나타나는
장면을 찾아 캡처한 뒤 학습지로 돌아와 사진을 제출합니다.

## 현재 초안 기능

- 2학년 고정
- A~E반 선택
- 이름 / 학번 입력
- 5개 탐방 지역 중 1곳 선택
- NAVER 지도 앱 URL Scheme 연동
- 모바일 사진 선택 및 미리보기
- Demo 저장소(localStorage) 업로드
- 반/지역별 결과 Gallery
- 실제 Google Drive 백엔드 교체를 위한 API adapter 분리

## 탐방 지역

1. 안산 원곡동 다문화마을특구
2. 이태원 이슬람 거리
3. 반포 서래마을
4. 대림동 차이나타운
5. 광희동 중앙아시아 거리

## 실행

GitHub Pages에서 정적 사이트로 바로 실행할 수 있습니다.

초기 상태에서는 `config.js`의 `storageMode`가 `demo`입니다.
Google Drive 백엔드가 준비되면 `api`로 변경하고 `backendUrl`을 지정합니다.

자세한 설정은 `SETUP.md`를 참고하세요.
